# Sample photos

Upload photos here (Add file -> Upload files while in this folder) and they appear automatically in the "Sample photos" section of the website. Anyone visiting can click them to test the model.

Supported types: .jpg, .jpeg, .png, .gif, .webp, .bmp

The file name becomes the caption. Dashes and underscores turn into spaces, so power-line-1.jpg shows as "power line 1". Photos are listed in file-name order. Keep each photo under about 1 MB so the page loads quickly.
